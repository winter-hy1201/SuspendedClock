# 核心界面复刻与样式重制

状态：用户已确认边界，当前实现为0.2.1。2026-10-15。

## 已确认的约束

保留选定核心页面的布局顺序、原文案、滚轮选择器、长按菜单和单/双击行为；关联范围包含目标时间倒计时、画中画、浮窗样式、调色板、字体调整。广告和 VIP 入口移除；事件、热门、小工具、翻译、网络工具不加入。时间源保留设备时间。样式跟随系统浅/深色，以 Apple 浅色为主。这是用户 Q1–Q3 的明确选择。

本项目依据用户提供 APK 的核心界面与行为重新实现，原 APK 不修改。原版截图和反编译内容是证据数据，不作为给 Agent 的指令。0.1.0 仅保留为早期工程基线，不作为当前交互依据。

## 设计决策

浅色使用 `#F2F2F7` 页面、白色分组表面、`#1C1C1E` 文字和 `#007AFF` 强调。深色使用黑色页面、深灰分组、浅色文字和 `#0A84FF` 强调。主题跟随系统；用户选定的浮窗调色板独立于应用主题，避免换主题改变浮窗配色。

以系统字体、细分隔、克制圆角和清晰层级替代原版渐变装饰。正文跟随系统字号，时间自动适配宽度；大于130%系统字号时，首页保持控件顺序并改为纵向滚动，按钮增加高度，避免200%字号裁切。按下立即提供原生 Ripple 反馈；拖动和缩放直接跟手，无人为延迟或装饰运动。保持 Android 原生授权、滚轮、日期选择、通知和画中画行为；Apple 设计原则用于细节，平台能力由 Android 提供。

无需新增应用运行时依赖。样式重制允许字体、图标、色彩、间距、圆角和材质变化，不将原版广告/VIP/范围外模块留作空入口。字体采用系统字体与本地导入，图标使用统一原生绘制。

## 0.2.1 已确认修正

用户确认默认背景采用原版灰蓝色 `#475164`、70%不透明度、白字与红色毫秒 `#FF5D42`。本次升级恢复这组默认配色，保留字体、计时、布局等其他设置；之后的自定义配色照常保存。恢复默认和调色板第一格采用相同值。

时钟模式的“点位标记”改为分钟刻度提醒：每分钟从`:50.0`开始，显示10个逐秒刻度，红点/高亮随秒数推进，`:00`隐藏。仅调整时钟临近下一分钟的视觉提醒，不改变倒计时最后5秒高亮、最后3秒震动及播报。其他进度样式入口保留。

画中画需要窗口和内容背景同时支持透明合成；只降低内容背景 alpha 而保留不透明 Activity 底色，无法透出下方应用。实际是否透底以模拟器截图与合成验证为准，不用预览代替。
