# 离线悬浮时钟

根据 `base.apk`（悬浮时钟 FloatingClock 1.1.11）的静态逆向与 BlueStacks 核心页面采集，重新实现的 Android 离线版本。保留选定核心页面的大体布局、入口顺序、文案和操作方式，用 Apple 风格的颜色、分组表面、字体与按压反馈重制细节。独立包名 `local.suspendedclock`，可与原版并存；原 APK 保持不变。

## 安装与使用

安装包：[offline-clock-0.2.1-debug.apk](releases/offline-clock-0.2.1-debug.apk)。本地调试签名开发版，支持 Android 8.0 / API 26 及以上，已安装到用户提供的 BlueStacks。

1. 首页「浮窗模式」选择「画中画」或「悬浮窗」，再点击底部开启按钮。悬浮窗首次使用按系统提示授权。
2. 悬浮窗可直接拖动；默认单击显示操作按钮，双击显示缩放手柄，拖动右下角手柄调整大小。单击、双击动作可在「悬浮窗设置」自定义。
3. 点击「倒计时」，用原生滚轮选择「目标时间」或「时长」，确认后开始。时长模式可在圆盘内暂停/继续；长按底部「倒计时」可重新开始、设置结束后显示内容。
4. 「切换模式」在时钟与倒计时之间选择；长按进入「显示模式管理」。点击上箭头展开「时钟控制」，支持长按菜单与拖动排序。
5. 右上角设置进入悬浮窗样式、调色板、字体调整等；「时钟 (当前模式)」配置时间格式、角落信息、水印、进度条和提醒。
6. 锁屏提醒需在「闹钟和提醒」允许精确提醒，并允许通知。锁定穿透后，从设置或运行通知的「解锁浮窗」恢复操作。

关闭浮窗不会重置倒计时。应用不会开机自启；设备重启后计时复位。后台服务仍受系统和厂商的电池策略影响。

## 0.2.1 修正

默认配色恢复原版灰蓝色 `#475164`、背景70%不透明度、白字和红色毫秒；本次升级会恢复默认配色，其他设置保留，之后仍可自定义。悬浮窗和画中画都使用透明窗口合成，可透出下方应用，而时间文字保持清晰。

时钟的“点位标记”仅在每分钟`:50`至`:59`显示10个逐秒刻度，红点/高亮每秒推进，下一分钟`:00`隐藏。倒计时结束前的高亮、震动、播报保持原有行为。

## 本次范围

- 悬浮窗和系统画中画；时钟、目标时间倒计时、时长倒计时。
- 七种时分秒格式，按原版显示一位小数的“毫秒”字段（十分之一秒），该字段约每100ms刷新；不代表毫秒级校时精度。
- 原版核心圆盘、四个控制入口、展开控制页、原生滚轮选择器、长按菜单、可配置单/双击动作。
- 六种浮窗布局、十二组配色、自定义背景/文字/毫秒颜色与透明度、本地图片背景、字体选择与本地字体导入、字号与偏移。
- 角落信息、设备时间、日期、屏幕刷新率、电量、水印、进度条、结束后停零/当前时间/正计时。
- 跟随系统浅/深色，以浅灰白和蓝色为浅色基础；设置仅保存在本机，不参与云备份。
- 无 INTERNET 权限，无广告、统计、账号、支付模块；应用运行时只依赖 Android SDK。

时间源入口仅提供设备时间。广告与 VIP 入口移除；事件、热门、小工具、翻译、网络工具、联网校时、循环模式与桌面组件不加入。字体示例沿用原版网格布局，具体字体使用 Android 系统字体或用户自行导入的本地字体，没有复制原版字体资产。画中画保留原版样式限制，最后两种细长布局仅在悬浮窗模式可选。

时长倒计时以包含休眠的 `elapsedRealtime()` 计算；目标时间倒计时以设备日期时间为准，修改设备时间会改变剩余时间。系统精确闹钟分别使用 `ELAPSED_REALTIME_WAKEUP` 和 `RTC_WAKEUP`。未授予精确提醒权限时，休眠到期通知可能延迟，唤醒后显示会校正。播报只选择已安装的离线中文语音；没有可用语音时关闭播报并提示。

[设计与复刻边界](docs/DESIGN.md) · [逆向记录](docs/REVERSE_ENGINEERING.md) · [实际验证记录](docs/VERIFICATION.md)。原版运行截图位于 `docs/original/`，重制截图位于 `docs/redesign/`。反编译为部分结果，不代表完整恢复原源码；模拟器检查不等于真机验收。

Agent 协作入口见 [AGENTS.md](AGENTS.md)。构建日志、工具下载和反编译缓存按 `.gitignore` 仅保留本地；历史记录中的本机路径用于说明当时环境，新环境按下方命令重新检查。

需要 JDK 17、Android SDK platform 36 / build-tools 36.0.0、Python 3 和 Bash。Gradle Wrapper 8.13，AGP 8.11.1。首次构建需下载工具依赖，缓存完整后可离线构建；应用安装后无需网络。

```bash
bash scripts/build.sh
# 构建工具缓存完整时
bash scripts/build.sh --offline
```

构建脚本运行 JVM 核心检查、APK 编译、Lint、实际 APK 权限及 SDK 扫描、签名检查，更新安装包与 `releases/SHA256SUMS`。脚本没有上传、提交、推送或发布步骤。

```bash
bash scripts/check-core.sh
python3 scripts/check-apk.py releases/offline-clock-0.2.1-debug.apk \
  --aapt "$ANDROID_HOME/build-tools/36.0.0/aapt"
adb connect 127.0.0.1:5555
adb -s 127.0.0.1:5555 install -r releases/offline-clock-0.2.1-debug.apk
```
